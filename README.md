# VK_bot_283

## Описание

Этот проект представляет собой бота для ВКонтакте, который автоматически отвечает на комментарии под постами с помощью ChatGPT. Бот использует MongoDB для хранения данных и работает через API ВКонтакте и OpenAI. 

## Переменные окружения

В файле `.env` хранятся конфиденциальные переменные, необходимые для работы бота. Заполните файл следующими данными:

```
- MONGO_HOST: Хост, на котором развернута база данных MongoDB (например, `localhost`).
- MONGO_PORT: Порт MongoDB, обычно это `27017`.
- MONGO_AUTH_DB: аза данных, используемая для аутентификации в MongoDB.
  
- VK_SECRET: Секретный ключ для подключения к API ВКонтакте.
- VK_ACCESS_TOKEN: Токен для доступа к API ВКонтакте для выполнения операций от имени бота.

- VK_GROUP_ID: ID группы ВКонтакте, в которой будет работать бот.
- VK_CONFIRMATION: Подтверждающий код для вебхуков ВКонтакте, который необходим для авторизации бота при получении уведомлений о новых комментариях.

- VK_APP_TOKEN: Токен приложения ВКонтакте, необходим для выполнения операций с API от имени вашего приложения.

- GPT_API_KEY: Ключ API для доступа к OpenAI (ChatGPT).
- GPT_BASE_URL: Базовый URL для подключения к API OpenAI (например, `https://api.proxyapi.ru/openai/v1`).
```

## Инструкция по настройке бота ВКонтакте

### 1. Создание сообщества
1. Перейдите в [раздел "Сообщество"](https://vk.com/groups) ВКонтакте.
2. Нажмите "Создать сообщество" и выберите подходящий тип.
3. После создания перейдите в своё сообщество.

### 2. Настройка API
1. В сообществе перейдите в "Управление".
2. Откройте вкладку "Работа с API".
3. Перейдите в раздел "Ключи доступа" и создайте новый ключ.
   - Сохраните этот ключ и добавьте его в переменную VK_ACCESS_TOKEN в файле .env.

### 3. Настройка CallBack API
1. Откройте вкладку "CallBack API".
2. Скопируйте строку из раздела "Строка, которую должен вернуть сервер".
   - Поместите её в переменную VK_CONFIRMATION в файле .env.
3. Придумайте "Секретный ключ".
   - Добавьте его в переменную VK_SECRET в файле .env.

Следуйте инструкции ниже или перейдите по ссылке и пройдите инструкцию там (https://dev.vk.com/ru/mini-apps/settings/development/keys#%D0%A1%D0%B5%D1%80%D0%B2%D0%B8%D1%81%D0%BD%D1%8B%D0%B9%20%D0%BA%D0%BB%D1%8E%D1%87)

### 4. Создание приложения ВКонтакте
1. Перейдите в [раздел "Приложения"](https://dev.vk.com/ru/admin/apps-list).
2. Создайте новое приложение.
3. В настройках приложения откройте "Разработка" -> "Ключи доступа".
4. Скопируйте "Сервисный ключ".
   - Добавьте его в переменную VK_APP_TOKEN в файле .env.

### 5. Указание ID группы
1. В VK_GROUP_ID в файле .env укажите ID группы, добавив перед ним знак минус (-).
   - Пример: VK_GROUP_ID=-123456789.

### 6. Укажите CallBack API "Адрес", на который придёт вебхук и подтвердите его

После выполнения этих шагов бот будет готов к работе.


## Запуск

1. После настройки `.env` и установки зависимостей, запустите скрипт:

   ```bash
   python app.py
   ```

2. Бот будет работать и отвечать на комментарии под постами в указанной группе ВКонтакте, используя OpenAI для генерации ответов.
