# VK_bot_283

## Описание

Этот проект представляет собой бота для ВКонтакте, который автоматически отвечает на комментарии под постами с помощью ChatGPT. Бот использует MongoDB для хранения данных и работает через API ВКонтакте и OpenAI. 

## Переменные окружения

В файле `.env` хранятся конфиденциальные переменные, необходимые для работы бота. Заполните файл следующими данными:

```
- **MONGO_HOST**: Хост, на котором развернута база данных MongoDB (например, `localhost`).
- **MONGO_PORT**: Порт MongoDB, обычно это `27017`.
  
- **VK_SECRET**: Секретный ключ для подключения к API ВКонтакте.
- **VK_ACCESS_TOKEN**: Токен для доступа к API ВКонтакте для выполнения операций от имени бота.

- **VK_GROUP_ID**: ID группы ВКонтакте, в которой будет работать бот.
- **VK_CONFIRMATION**: Подтверждающий код для вебхуков ВКонтакте, который необходим для авторизации бота при получении уведомлений о новых комментариях.

- **VK_APP_TOKEN**: Токен приложения ВКонтакте, необходим для выполнения операций с API от имени вашего приложения.

- **GPT_API_KEY**: Ключ API для доступа к OpenAI (ChatGPT).
- **GPT_BASE_URL**: Базовый URL для подключения к API OpenAI (например, `https://api.proxyapi.ru/openai/v1`).
```


## Запуск

1. После настройки `.env` и установки зависимостей, запустите скрипт:

   ```bash
   python app.py
   ```

2. Бот будет работать и отвечать на комментарии под постами в указанной группе ВКонтакте, используя OpenAI для генерации ответов.
